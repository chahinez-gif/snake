# 🐍 Snake — Jeu Web

Jeu Snake classique développé en HTML, CSS et JavaScript vanilla.

## Fonctionnalités

- Déplacement fluide du serpent
- Système de score et meilleur score
- Niveaux progressifs (vitesse augmente)
- Contrôles clavier et mobile
- Interface rétro avec effets lumineux

## Lancer le jeu

Ouvre simplement `index.html` dans ton navigateur.

## Contrôles

| Touche | Action |
|--------|--------|
| ⬆ / Z | Haut |
| ⬇ / S | Bas |
| ⬅ / Q | Gauche |
| ➡ / D | Droite |
| ESPACE | Pause / Jouer |

## Structure

```
snake/
├── index.html   # Structure de la page
├── style.css    # Interface et animations
├── snake.js     # Logique du jeu
└── README.md    # Documentation
```
